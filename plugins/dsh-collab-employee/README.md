# dsh-collab-employee

Employee Identity Foundation for the three-tier employee model. It maps existing
Identity login accounts to durable Human Employee records and provides a
minimal directory for future Digital Employees.

The `E1` scope intentionally does not create login accounts for Digital
Employees, does not make Human Avatar records employees, and does not replace
existing `userId` APIs. The preferred Employee ID for a migrated Human Employee
is its existing Identity user ID.
