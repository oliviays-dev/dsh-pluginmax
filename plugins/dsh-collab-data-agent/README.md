# dsh-collab-data-agent

Platform built-in Data Agent for `dsh-pluginmax`.

- Uses the protected `data-agent` AI伙伴 identity and the existing Principal /
  Runtime Profile / Agent Run chain.
- Keeps conversations, context attachments, runs, Markdown reports, on-demand
  HTML derivatives, ownership, and audit records in the `collab_data_agent`
  storage domain.
- Exposes a shared side-panel tab and a global page-header action. It never
  creates a second chat or runtime implementation.
- Default analysis is read-only. Write, external publish, and assignment flows
  remain behind action tickets or explicit human confirmation.
