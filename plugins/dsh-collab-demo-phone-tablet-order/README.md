# dsh-collab-demo-phone-tablet-order

Optional, detachable phone/tablet finished-goods order demo.

This package owns its fixture, Mock OMS and WMS MCP servers, task action card,
workbench display profile, prompts and Demo receipts. Shared platform code only
provides generic MCP provider routing, task-detail slots and workbench display
profile registration.

The task plugin renders `pluginmax.task.detail.extension` as a visible,
content-sized business action area. Empty slots create no placeholder. The Demo
workbench profile reads `metrics.selected` from `config/workbench-profile.yaml`
and restores the four original metric cards. `otif` is queried through the Mock
OMS MCP, while inventory turnover, supplier on-time delivery, and procurement
price achievement retain their static demo values. The formal workbench seed and
preferences are unchanged. When the optional workbench V2 host is installed,
only an empty Demo workspace is seeded with the brief, todo, metrics, and focus
panels. Existing personalized layouts are never rewritten by metric refreshes,
profile preparation, or plugin reloads.

The complete storyboard and acceptance gate live in
`docs/demos/phone-tablet-order-exception-demo-script.md`. Keep one human child
task and one AI child task:

- `PT-ORD-001-B` -> `履约 AI 伙伴`;

The second business AI partner is `周宁的AI小助理`. It does not receive a
three-level task. Zhou Ning uses an AI 1:1 conversation to provide the verified
QueryRun, Li Gong's receipt and the WMS receipt. An external CodeBuddy runtime
must generate a self-contained HTML report and return it as a real attachment
in that conversation. Zhou Ning downloads the file, manually uploads it to the
parent task, and submits Lin Lan's review.

Data Agent remains the built-in read-only analysis identity and does not count
as one of the two configured business AI partners. It is used for chat briefs
only in this demo; it does not generate the management report.

The CodeBuddy provider selector and AI-chat file artifact return are currently
formal platform gaps. Do not record or simulate those steps until the generic
contract in `docs/demos/phone-tablet-order-demo/developer-change-prompt.md` is
implemented. A local path, screenshot, hand-written link, or human-uploaded file
must never be presented as an AI-generated attachment.

Before recording, copy this package's prepared project inputs into the current
`手机平板订单履约演示` project space. Keep these file names:

```text
00-手机平板订单异常-资料索引.md
PT-ORD-001-B-履约证据包.md
PT-ORD-001-RPT-管理报告证据包.md
```

Task B reads only the index and the B evidence pack. 周宁的AI小助理 reads only
the index and the report evidence pack by file name inside the current project
space. Neither agent should scan outside the project or connect an external
document provider. The assistant may search public web sources only when public
terminology, regulation, or external context needs verification; web results
must not replace internal order or fulfillment facts.

Enable the package only through:

```sh
PLUGINMAX_ENABLE_PHONE_TABLET_DEMO=1 ./scripts/install-profile.sh
```

The WMS business write is performed through the standard MCP tool
`wms_rebalance_work_order_create`. The package HTTP routes only authenticate a
human, issue and validate an Action Ticket, invoke that MCP tool, and persist
the task receipt. No Demo REST route writes business data directly.

Preview and remove Demo-owned storage before deleting the package:

```sh
DSH_HOME="$PWD/.tmp/dsh-home" \
  node plugins/dsh-collab-demo-phone-tablet-order/scripts/remove-demo-state.mjs

DSH_HOME="$PWD/.tmp/dsh-home" \
  node plugins/dsh-collab-demo-phone-tablet-order/scripts/remove-demo-state.mjs --apply
```

The cleanup removes the two MCP install records, tasks in
`手机平板订单履约演示`, the `履约 AI 伙伴` instance, Demo order/Data Fabric
records, profile brief items, task receipts, runtime fixture and WMS state.
The AI assistant 1:1 conversation and generated HTML attachment must also be
checked and removed when they are implemented.
It does not remove teammate work report or audit event rows generated by the
Demo instance; check those separately when using a shared `DSH_HOME`.
Then remove `dsh-collab-demo-phone-tablet-order` from the profile, unset
`PLUGINMAX_ENABLE_PHONE_TABLET_DEMO`, and restart the host.
