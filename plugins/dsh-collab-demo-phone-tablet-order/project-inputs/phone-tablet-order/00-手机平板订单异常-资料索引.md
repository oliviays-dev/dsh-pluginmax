## Agent 读取规则

1. 文件读取只使用当前项目空间内下列固定文件名的 Markdown，不扫描项目外目录，
   不连接网盘、邮件、IM、共享文档或其他文档平台。
2. 履约 AI 伙伴不需要联网。周宁的AI小助理如确有必要，可联网搜索公开资料用于术语、
   法规或外部背景核实；不得用联网结果推断内部订单、库存、WMS、客户或仓配事实。
3. 先读取本索引，再按下表读取当前任务对应的唯一证据包。
4. 任务描述、任务后续消息或当前 1:1 用户消息中的明确事实优先于本资料包。
5. 文件中的 `{{...}}` 是运行时占位符。未由人类替换时，不得编造，也不得为了补字段调用外部数据源。
6. 文件内容不足时，明确指出缺少哪个字段一次，再基于已有事实继续完成可完成的部分；
   不要反复申请与本任务无关的文件授权，也不要为寻找订单信息不断更换数据源。

## 固定边界

- 原 C 报告职责现在由 AI伙伴 1:1 承接，不创建 `[PT-ORD-001-C]` 任务。
- 履约 AI 伙伴只生成工单草稿，不执行 MCP 写调用。
- 报告伙伴只整理 HTML，不重新查询 Data Agent，不调用 WMS；必要时可对公开信息做有限联网核实。
- 所有业务写操作继续由人类确认、Action Ticket 和标准 MCP `tools/call` 完成。
- 本资料包不包含真实客户姓名、手机号、地址、SKU 明细、IMEI/SN 或生产订单数据。
