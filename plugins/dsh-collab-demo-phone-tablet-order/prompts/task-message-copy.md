# 任务输入、回执与老板 Review 文案

> 业务结构：父任务 1 个、人工三级任务 1 个、AI 三级任务 1 个。
> 两个业务 AI 伙伴：履约 AI 伙伴承接 B 任务；周宁的AI小助理通过 1:1 沟通生成管理报告，不承接任务。

## 项目内资料准备

把 Demo 插件准备的项目资料复制到当前项目空间，录制前应能按文件名找到：

```text
00-手机平板订单异常-资料索引.md
PT-ORD-001-B-履约证据包.md
PT-ORD-001-RPT-管理报告证据包.md
```

履约 AI 伙伴的文件读取只限这些项目内文件，不访问网页、网盘、邮件、IM、
共享文档或生产系统。周宁的AI小助理同样只从项目空间读取文件，但如确有必要，
可以联网搜索公开术语、法规或外部背景，不得用网页结果推断内部订单或仓配事实。
项目内文件已经提供订单事实和处置约束时，不要在任务中反复申请无关文件授权。

```text
3. 出库前需要绑定 IMEI/SN，跨仓交接需要库存归属审核；
4. 运输需要保价并完成高货值交接，签收需要身份核验；
5. 发票与售后登记信息随订单同步。

建议将 37 单转入成品仓订单再平衡，当天 17:00 前完成库存锁定和仓间交接。
其余订单按退款、取消或改约处理。
```

```text
确认人：周宁
操作者：履约 AI 伙伴
```

```text
人类点击确认
→ Demo 服务校验周宁和工作区
→ 签发 5 分钟有效的 HMAC Action Ticket
```

## 周宁的AI小助理：1:1 报告

该伙伴不是三级任务责任人。回执回来后，周宁打开“沟通 → 新建沟通 → AI伙伴 1:1”，
选择 `周宁的AI小助理`，发送
[ai-assistant-prompt.md](./ai-assistant-prompt.md) 中的实际输入。

小助理先按文件名读取当前项目空间内以下文件：

```text
00-手机平板订单异常-资料索引.md
PT-ORD-001-RPT-管理报告证据包.md
```

不要让它为了寻找订单信息扫描项目外文件或反复申请无关文档授权。

必须使用真实值替换：

```text
QueryRun ID
dataCutoffAt
permissionSummary
指标版本
李工回执
Action Ticket
WMS 工单号
```

期望生成并返回：

```text
华东手机平板订单问题排查和处理报告.html
MIME：text/html
单文件、内联 CSS/SVG、无远程资源
当前 1:1 会话中显示可下载附件
```

报告至少包含：

1. 首屏管理结论；
2. 订单量、异常量、异常率、恢复履约等 KPI；
3. 支付失败、履约超时、取消的构成图；
4. Data Agent QueryRun、数据截止、指标版本和权限；
5. 李工人工核实结果；
6. 人工确认、Action Ticket、MCP tools/call 和 WMS 回执；
7. 处置时间线；
8. `126 = 83 + 43`、`83 = 46 + 37` 和工单关系；
9. 剩余风险和下一步；
10. “演示数据 · 非生产 · 待人工核验，未对外发送”。

只有文本路径、没有真实附件时停止录制。

## 周宁下载、上传父任务并提交老板 Review

1. 在 1:1 对话下载 HTML。
2. 本地打开，核对图表、数字、证据链和剩余风险。
3. 返回 `[PT-ORD-001]`。
4. 在统一输入区选择“指令”，附加 HTML。
5. 发送说明：

```text
已完成订单异常排查和处置复盘。附件为给林岚的管理报告：
- 126 单全部形成结论；
- 83 单恢复履约，其中 46 单支付恢复、37 单成品仓订单再平衡；
- 43 单退款、取消或改约；
- 37 单工单为 WO-RB-DEMO-1030-017；
- 报告中的 QueryRun、Data Agent 权限、人工回执和 MCP 回执均已核对。
请 Review。
```

6. 勾选父任务验收标准。
7. 点击“提交验收”。
8. 切换林岚，打开 `[PT-ORD-001]`。
9. 从任务附件或文档区下载 HTML，核对后点击“通过”。

### 次日收作业

1. 周宁打开“AI伙伴 → 工作计划”，确认三条任务进入“待确认”。
2. 打开工作日报，展示“无人值守执行小结 · 3 项”。
3. 逐条查看报告、公开来源和待确认事项。
4. 对满足验收标准的任务点击“通过”；信息不足的任务退回补充。
5. 不把工作日报或夜间执行小结当作自动验收。
