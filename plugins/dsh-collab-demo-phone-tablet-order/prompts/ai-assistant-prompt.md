# 周宁的AI小助理：运行配置与一对一报告提示词

> 适用版本：2026-11-03
> 业务 AI 伙伴：2 个之一，不占三级任务
> 输出物：`华东手机平板订单问题排查和处理报告.html`
> 载体：AI伙伴 1:1 沟通

## 录制前置状态

截至当前工作区，以下能力尚未形成可录制的完整闭环：

1. “运行时设置”的 Provider 下拉只有 `Codex / WorkBuddy / 通用命令`，没有独立的 `CodeBuddy` 选项；
   服务端进程适配器虽然已支持 `provider=codebuddy`，但创建运行时接口和页面都还没有放行。
2. 外部 Runtime 可以执行 CodeBuddy 并在项目工作区写文件，但运行结果只返回文本，
   没有通用文件 artifact 结构。
3. 一对一回复由 `postWorkerReply(participantId, content)` 写回，只接收文本；
   消息模型支持附件，但 AI 回复链路没有附件参数。

因此，正式录制必须等
[developer-change-prompt.md](./developer-change-prompt.md) 中的 P0 项完成后执行。
在文件附件真实出现在 1:1 对话之前，不得用本机文件、静态截图、手写链接或人工上传冒充
“AI 在对话中返回报告”。

## 注册 CodeBuddy 运行时

使用周宁登录：

1. 打开“AI伙伴”。
2. 进入“运行时设置”。
3. 点击“注册运行时”。
4. 填写：

```text
运行时名称：CodeBuddy · 订单管理报告
Provider：CodeBuddy
协议：通用 stdin/stdout（由 CodeBuddy 适配器托管 stream-json）
命令：codebuddy
工具：读取文件、写入文件、网页搜索
文件修改权限：自动接受文件修改
最大上下文窗口：按实际 CLI 能力填写
```

5. 保存后点击“探测”。
6. 确认状态为“启用中”，最近探测通过。

网页搜索仅用于公开术语、法规或外部背景核实；订单、库存、WMS、客户和仓配事实
必须继续来自项目内资料与当前 1:1 消息。

当前页面若没有 `CodeBuddy` Provider，停止录制。不要用显示为 `WorkBuddy` 的选项冒充
CodeBuddy 页面；也不要通过隐藏 API 预置后再声称页面支持。

## 创建 AI 小助理

1. 打开“AI伙伴 → 智能体定义”。
2. 基于个人模版创建定义，将 [ai-assistant-soul.md](./ai-assistant-soul.md) 的 SOUL 写入。
3. 回到“AI伙伴管理”，用该定义创建实例。
4. 实例名称填写 `周宁的AI小助理`。
5. 执行方式选择“外部 Agent”，绑定 `CodeBuddy · 订单管理报告`。
6. 确认实例为“生效”，owner 显示为实际创建人周宁。
7. 打开“沟通”，点击“新建沟通”，选择“AI伙伴 1:1”，选择该实例并点击“开始 1:1 沟通”。

确认当前项目空间内已有以下文件：

```text
00-手机平板订单异常-资料索引.md
PT-ORD-001-RPT-管理报告证据包.md
```

这两份文件是当前项目空间内的只读资料。小助理应先直接读取，不要扫描项目外文件，
也不要为寻找订单信息反复申请无关文件授权。若报告确需核实公开术语、法规或外部背景，
允许进行有限联网搜索，但不得用网页内容替代内部订单和仓配事实。

## 1:1 实际输入

在周宁与 `周宁的AI小助理` 的一对一沟通中粘贴以下内容。
所有 `{{...}}` 必须替换为本次运行的真实值。

```text
请先读取项目内的以下两个文件，再开始整理：
- 00-手机平板订单异常-资料索引.md
- PT-ORD-001-RPT-管理报告证据包.md

文件读取只限以上当前项目空间内文件，不要扫描项目外目录，也不要连接网盘、邮件或 IM。
如报告确需核实公开术语、法规或外部背景，可以有限联网搜索并标注公开来源和访问时间；
联网结果不得用于推断内部订单、库存、WMS、客户或仓配事实，也不得上传项目资料。
文件不存在或无法读取时直接说明一次，不要反复申请无关文件授权或改查生产系统。

帮我给林岚整理一份可以直接看的订单问题排查和处理报告，生成单文件 HTML：
《华东手机平板订单问题排查和处理报告》，文件名用
“华东手机平板订单问题排查和处理报告.html”。

这次只使用我下面给你的已确认事实，不要重新查数据，也不要调用订单或仓库系统。

【订单异常事实】
今天华东数码（手机、平板）订单 1,658 单，异常 126 单，异常率 7.6%。
异常构成：支付失败 52 单、履约超时 43 单、取消 31 单；分别占异常量
41.3%、34.1%、24.6%，按订单去重。
订单异常口径为支付失败、取消、履约超时；退款和金额异常不计入。
订单金额 8,420,218 元，异常订单金额 642,748 元。
数据为演示数据，非生产。
QueryRun：{{真实 QueryRun ID}}
数据集：orders-facts
指标版本：{{真实指标 ID 与 orders-metric-v1}}
数据截止：{{真实 dataCutoffAt}}
权限摘要：{{原样粘贴真实 permissionSummary}}
权限解释：当前账号是 Workspace Member，授权覆盖华东、华南，华北、西南未覆盖；
未覆盖区域不能按 0 异常处理。

【李工人工回执】
{{原样粘贴李工任务回执}}

【处置结果】
126 单已全部形成处置结论：83 单恢复履约，43 单退款、取消或改约。
83 单中，46 单通过支付恢复，37 单通过成品仓订单再平衡完成处置。
37 单对应业务工单 WO-RB-DEMO-1030-017，预计订单金额 194,125 元。
人工确认人：周宁
Action Ticket：AT-PT-ORD-001-B
MCP 调用：tools/call · wms_rebalance_work_order_create
幂等键：PT-ORD-001-B

报告要求：
1. 首屏先给管理结论，清楚回答“问题有多大、为什么不是单一库存问题、现在处理到什么程度”。
2. 用 KPI 卡展示订单量、异常量、异常率、恢复履约和待完成事项。
3. 用内联 SVG 或 CSS 图展示异常构成，并给出真实数字和占比。
4. 写出证据链：Data Agent 只读查询、李工人工核实、人类确认、Action Ticket、
   MCP tools/call 和 WMS 回执。
5. 明确区分订单事实、人工仓配事实和待核实原因；不要根据订单字段猜 SKU、
   IMEI/SN、库存或仓配作业状态。
6. 写清 83 + 43 = 126、83 = 46 + 37，以及 37 单和工单号的关系。
7. 列出处置时间线、剩余风险和下一步，不用“持续关注”“加强协同”这类空话。
8. 报告结尾标注“演示数据 · 非生产 · 待人工核验，未对外发送”。
9. 使用内联 CSS/SVG，不引用远程图片、字体、脚本、样式或截图。
10. HTML 控制在 512 KiB 以内。
11. 生成成功后，在当前 1:1 对话直接返回可下载的 HTML 文件；不要只回复文件路径。
```

## 预期回复与附件

AI 应返回简短交付说明，并附上：

```text
华东手机平板订单问题排查和处理报告.html
text/html
单文件，可离线打开
[下载]
```

交付说明应明确：

- 报告只使用本轮 1:1 提供的事实；
- 已读取项目内索引和 `PT-ORD-001-RPT-管理报告证据包.md`；
- Data Agent 未查询 SKU、IMEI/SN、库存或 WMS；
- 业务工单来自人工确认后的标准 MCP 回执；
- 报告待当前任务验收人检查，尚未外发。

如果只有文本路径、没有可下载附件，视为平台能力未完成，停止录制。

## 周宁下载与父任务上传

1. 在 1:1 对话点击附件下载 HTML。
2. 在本地浏览器打开，核对 KPI、图表、证据、时间线、对账和风险。
3. 打开 `[PT-ORD-001]` 父任务。
4. 在统一输入区选择“指令”，附加 `华东手机平板订单问题排查和处理报告.html`。
5. 填写发送说明：

```text
已完成订单异常排查和处置复盘。附件为给林岚的管理报告：
- 126 单全部形成结论；
- 83 单恢复履约，其中 46 单支付恢复、37 单成品仓订单再平衡；
- 43 单退款、取消或改约；
- 37 单工单为 WO-RB-DEMO-1030-017；
- 报告中的 QueryRun、Data Agent 权限、人工回执和 MCP 回执均已核对。
请 Review。
```

6. 发送附件消息。
7. 勾选父任务验收标准，点击“提交验收”。
8. 切换林岚，打开父任务中的 HTML 附件。
9. 核对后点击“通过”。

## 失败时的自然追问

没有附件时：

```text
我只看到文字说明，没有看到可下载的 HTML 文件。请把本轮生成的报告作为附件返回；
如果平台无法返回文件，直接说明哪一步没有跑通，不要给我本地路径。
```

报告缺少证据时：

```text
把 QueryRun、dataCutoffAt、权限摘要、Action Ticket 和 WMS 工单回执补齐；
找不到的值标成缺失，不要补造。
```

## 禁止话术

- “小助理重新查了一遍订单。”
- “小助理读取了 Data Agent 的完整会话。”
- “CodeBuddy 已经调用 WMS。”
- “报告已经自动发给了林岚。”
- “文件路径等同于 1:1 对话附件。”
