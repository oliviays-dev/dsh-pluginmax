# 华东手机/平板订单异常处置复盘

> 数据状态：演示数据 · 非生产  
> 时间范围：当天 00:00 至 Data Agent 查询截止时间  
> 业务范围：华东 · 数码（手机/平板）  
> 权限覆盖：华东、华南；华北、西南未覆盖

## 一、结论

当天华东数码订单异常 126 单，异常率 7.6%。异常由支付失败、取消和履约超时共同构成，不是单一库存问题。

截至处置完成：

- 83 单恢复履约；
- 43 单进入退款、取消或改约；
- 37 单通过 `WO-RB-DEMO-1030-017` 成品仓订单再平衡工单完成跨仓库存调拨和订单改派。

## 二、异常构成

| 异常类型 | 订单量 |
| --- | ---: |
| 支付失败 | 52 |
| 取消 | 31 |
| 履约超时 | 43 |
| 去重后异常合计 | 126 |

口径：订单异常 v1 = 支付失败 + 取消 + 履约超时，按订单去重；退款和金额异常不进入默认异常口径。

异常订单金额约 64.3 万元，占当天华东数码订单金额约 7.6%。

## 三、执行过程

### 3.1 订单异常评估

Data Agent 基于 `orders-facts` 只读查询完成异常构成分析，并保留 QueryRun、指标版本、数据截止时间和权限摘要。

订单数据能够定位区域、品类、渠道、商家、支付方式和金额，但不能单独确认具体 SKU、IMEI/SN、库存或成品仓作业状态。

### 3.2 成品仓核实

王工核实华东成品仓后确认：

- 部分手机和平板 SKU 在原履约仓没有可立即出库的完整序列号库存；
- 华东备用成品仓存在可用库存；
- 跨仓履约需要完成库存归属变更、IMEI/SN 扫描、保价运输、身份核验签收和发票同步；
- 37 单可在当天 17:00 前完成库存锁定和仓间交接。

### 3.3 业务动作

履约 AI 伙伴基于订单异常范围和人工核实结果生成成品仓订单再平衡工单草稿。周宁确认后，履约 AI 伙伴通过资源市场注册的 Mock WMS MCP 调用 `wms_rebalance_work_order_create`，返回：

```text
业务工单：WO-RB-DEMO-1030-017
状态：已创建
涉及订单：37 单
操作者：履约 AI 伙伴
调用协议：MCP tools/call
确认人：周宁
审计引用：AT-PT-ORD-001-B
```

## 五、剩余风险

1. 37 单需要在 17:00 前完成库存锁定和仓间交接，否则可能转为改约。
2. 订单数据不包含 SKU、IMEI/SN 和实物库存，复盘中的仓配事实来自人工回执，不能反写成 Data Agent 查询结果。
3. 本演示使用 Mock WMS，不代表真实生产系统已写入。
4. 华北、西南未覆盖，不能将未覆盖区域推断为零异常。
