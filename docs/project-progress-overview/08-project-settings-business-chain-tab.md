# 项目设置「业务链路」页签交互规格

> 文档状态：交互与技术设计稿  
> 页面位置：项目管理 → 项目详情 → 项目设置  
> 页签顺序：基础信息 / 项目角色 / **业务链路**  
> 目标：让用户能配置项目业务链路，同时保持「项目概览」只读、可解释、可追溯。

项目可用业务链路由项目类型和项目模版治理。供应链交付只是其中一种场景，页面不得从全平台工作流中任意挑选。

## 1. 交互结论

「业务链路」配置放在项目设置中是合理且推荐的位置。

原因：

- 项目概览是消费和处置界面，不应同时承担流程建模。
- 项目设置已经是项目级定义的集中入口，业务链路与项目角色同层。
- 工作流模块负责定义本体和版本，项目设置负责选择、绑定和校验。
- 「任务清单」「工作流」页签继续展示运行实例，不出现定义与实例混层。

页面职责边界：

| 页面 | 职责 |
| --- | --- |
| 项目设置 → 业务链路 | 从项目模版允许范围中选择业务链路、绑定节点来源、校验数据源、应用或启动 |
| 项目概览 | 只读展示业务链路节点、业务事实、异常、Alert 和变更事件 |
| 项目模版维护 | 配置默认业务链路、候选业务链路、版本策略和适用项目类型 |
| 工作流 → 工作流模版管理 | 新建、编辑、版本化业务链路定义本体 |
| 工作流页签 | 查看和执行工作流实例 |
| 计划 / 订单 / 库存 / 产能系统 | 业务事实主数据 |

## 2. 页签位置

在现有项目设置页签中新增第三个页签：

```text
项目设置
  ├─ 基础信息
  ├─ 项目角色
  └─ 业务链路
```

页签规则：

- 默认仍进入「基础信息」。
- 页签文案固定为「业务链路」，不使用「主干流程」「流程图」等近义名称。
- 需要状态或数量时写成「业务链路 3」，不显示括号。
- 未绑定业务链路时，页签仍可见，显示空态。
- 非项目负责人或平台管理员不能打开项目设置。

## 3. 页面结构

### 3.1 页签头部

```text
业务链路                                       [校验绑定] [选择业务链路]
AI Server 交付链路 · v3 · 已绑定               计划/订单/库存/产能：3 正常 · 1 延迟
```

第一行是区块标题和操作。

第二行只展示：

- 当前业务链路名称。
- 版本。
- 绑定状态。
- 数据源健康摘要。

不展示功能说明段。

### 3.2 当前业务链路

使用紧凑摘要，不使用三个大卡片：

| 字段 | 示例 |
| --- | --- |
| 业务链路定义 | AI Server 交付链路 |
| 定义版本 | v3 |
| 定义来源 | 项目模版「AI Server 交付模版」 |
| 绑定状态 | 已绑定 |
| 当前实例 | WF-SO0101-20261116 / 进行中 |
| 最后校验 | 2026-11-18 12:00 |

无业务链路时显示：

```text
当前项目还没有业务链路。请先在项目模版中配置，或从当前模版允许的链路中选择。
```

操作：

- 选择业务链路；只有项目模版配置了多个候选时才展示。
- 上传项目级业务链路配置；支持 `.md` 工作流定义和 `.json` 业务链路配置。
- 查看工作流模版。
- 校验绑定。

项目级上传会生成或引用当前项目可见的业务链路定义，并保存为
`bindingMode = project-custom` 的项目快照。上传或选择候选后，页签下方按项目概览
相同的节点图交互展示配置预览：节点选中、缩放、复位、全屏和 Esc 退出。

### 3.3 节点与数据源

使用表格，不使用节点卡片堆叠。

平台默认只展示节点的「负责人」和「异常」。节点其余字段由业务链路定义；
供应链场景下可以声明「原计划」「变更后」「实际完成」等字段，其他项目类型可以
声明自己的字段。项目设置只负责绑定这些字段引用的外部对象与来源。

| 顺序 | 业务链路节点 | 工作流状态 | 计划来源 | 订单来源 | 库存来源 | 产能来源 | 绑定状态 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 订单接入 | 已完成 | PLN-01 | SO-1018-01 | — | — | 已绑定 |
| 3 | 供应备货 | 进行中 | PLN-03 | — | KIT-SO0101 | — | 来源延迟 |
| 4 | 生产总装 | 等待中 | PLN-04 | — | — | LINE-AI-02 | 已绑定 |

每行操作：

- 绑定来源。
- 查看来源。
- 清除绑定，危险操作，需要确认。

表格只展示绑定和健康状态，不展示详细业务数字。详细业务数字在项目概览查看。

### 3.4 数据源健康

采用一行状态列表：

```text
计划系统 正常 · 12:00
订单系统 正常 · 11:58
库存系统 延迟 · 11-15 08:00
产能系统 正常 · 12:00
```

状态词：

| 状态 | 含义 |
| --- | --- |
| `正常` | 在 SLA 内 |
| `延迟` | 超过 SLA，但仍有最后快照 |
| `异常` | 最近读取失败 |
| `未接入` | 当前节点未声明该来源 |

页面不得把“延迟”写成“已解决”或隐藏数据。

### 3.5 工作流实例

业务链路页签只管理业务链路实例引用，不复制工作流详情。

无实例：

```text
业务链路已绑定，尚未启动业务链路实例。
[启动业务链路实例]
```

有实例：

```text
当前实例：WF-SO0101-20261116 · 进行中
[详情] [打开工作流]
```

更换定义时不自动迁移运行中实例。必须提示：

```text
已运行实例继续使用启动时的定义快照，新绑定仅影响后续实例和项目概览。
```

## 4. 用户操作流程

### 4.1 选择业务链路

```text
点击「选择业务链路」
  → 读取项目来源模版的业务链路策略
  → 打开当前模版允许的候选列表
  → 只显示状态为启用且在当前模版 allowedBusinessChainTemplateIds 中的链路
  → 选择后进入绑定草稿
  → 展示节点和来源预览
  → 校验绑定
  → 应用业务链路
```

候选列表字段：

| 字段 | 说明 |
| --- | --- |
| 名称 | 业务链路定义名称 |
| 版本 | v1 / v2 / v3 |
| 来源模版 | AI Server 交付模版 |
| 阶段数 | 7 个节点 |
| 来源类型 | 计划、订单、库存、产能 |
| 状态 | 启用 |
| 更新时间 | yyyy-mm-dd hh:mm |

候选列表不展示普通执行工作流，也不展示其他项目模版未授权的业务链路。

### 4.2 预览与节点映射

选择定义后先进入预览，不立即覆盖当前配置。

预览内容：

- 业务链路节点顺序。
- 每个节点已有 `stageCode`。
- 已绑定来源。
- 未绑定或无效来源。
- 来源过期状态。
- 与当前定义的差异。

差异条：

```text
新增 1 个节点 · 修改 2 个来源 · 移除 0 个节点
```

### 4.3 手动绑定来源

节点来源使用抽屉或子面板，不嵌套二级弹窗。

```text
绑定来源
节点：供应备货

来源系统：[计划系统 ▼]
对象类型：[计划节点 ▼]
对象：PLN-SO0101-M03 · 供应备货 · 11-30

[取消] [确认绑定]
```

要求：

- 只返回当前项目可访问对象。
- 显示对象名称、业务编号和最近更新时间。
- 不自动猜测订单、库存或产能对象。
- `stageCode` 和 `objectId` 匹配只作为推荐，不能无确认直接写入。

### 4.4 校验绑定

点击「校验绑定」时检查：

1. 业务链路是否属于当前项目模版允许范围。
2. 业务链路定义是否存在、启用且为 `business-chain`。
3. 当前实例是否属于该定义。
4. 节点 `stageCode` 是否唯一。
5. 所有 required `externalRefs` 是否有效。
6. MCP 返回对象是否属于当前项目。
7. 来源新鲜度、权限和 schema。
8. 运行中实例是否存在版本不兼容。

结果分三组：

| 结果 | 用户动作 |
| --- | --- |
| 阻断 | 修复后才能应用 |
| 警告 | 可应用，但需确认 |
| 通过 | 可以应用或启动 |

示例阻断：

```text
节点「生产总装」缺少产能资源绑定。
```

示例警告：

```text
库存系统最后同步时间已超过 SLA 2 天，项目概览将显示“来源延迟”。
```

### 4.5 应用业务链路

点击「应用业务链路」后：

1. 校验 revision，避免并发覆盖。
2. 保存 `businessChainBinding` 项目快照。
3. 不修改已有运行实例的历史快照。
4. 清理项目概览旧 Read Model。
5. 触发项目概览重新加载。
6. 写入项目审计。

影响预览：

```text
将把项目概览切换为「AI Server 交付链路 v3」。
当前运行实例 WF-SO0101-20261116 不受影响。
```

### 4.6 启动业务链路实例

启动操作复用工作流现有实例启动流程：

- 选择项目。
- 确认角色映射。
- 确认来源绑定。
- 启动实例。
- 返回项目设置并刷新当前实例。

启动成功后：

```text
已启动业务链路实例 WF-SO0101-20261118。
```

启动失败时保留用户选择和校验结果，不清空表单。

## 5. 未保存守卫

以下情况存在未应用草稿：

- 已选择新定义但未应用。
- 已修改节点来源绑定。
- 已改变启动参数。

关闭项目设置、切换页签、切换项目时：

```text
放弃业务链路修改？
当前修改尚未应用。
[继续编辑] [放弃修改]
```

不能在未提示时丢失用户选择。

## 6. 权限

| 能力 | 权限 |
| --- | --- |
| 查看项目概览 | 项目成员 / 平台管理员 |
| 打开业务链路页签 | 项目负责人 / 平台管理员 |
| 选择并应用业务链路 | 项目负责人 / 平台管理员 |
| 启动业务链路实例 | 工作流启动权限 + 项目成员身份 |
| 编辑工作流模版本体 | 工作流模块现有权限 |
| 编辑外部来源数据 | 不允许 |

如果用户不能编辑：

- 项目设置入口不展示。
- 直接调用写接口必须返回 403。
- 不能在只读页面放 disabled 输入框伪造编辑能力。

## 7. 状态设计

### 7.1 Loading

```text
正在读取业务链路配置…
```

### 7.2 Empty

```text
当前项目还没有业务链路。请先在项目模版中配置，或从当前模版允许的链路中选择。
```

### 7.3 Error

```text
业务链路加载失败：工作流服务不可用。请稍后重试。
[重试]
```

### 7.4 Partial

```text
业务链路已加载，库存和产能来源暂不可用。
项目概览会显示最后快照和“来源延迟”提示。
```

### 7.5 Conflict

```text
业务链路已被其他管理员更新。请重新加载后再应用。
[重新加载]
```

## 8. 页面数据接口建议

### 8.1 读取业务链路配置

`GET /api/collab/projects/business-chain?workspaceId=...`

返回：

```json
{
  "ok": true,
  "businessChain": {
    "definitionId": "wfdef-business-chain-ai-server-v3",
    "projectTemplateId": "tpl-supply-ai-server",
    "businessChainTemplateId": "chain-supply-standard",
    "definitionVersion": 3,
    "name": "AI Server 交付链路",
    "bindingMode": "explicit",
    "instanceId": "wf-instance-so0101",
    "instanceStatus": "running",
    "revision": 4,
    "lastValidatedAt": "2026-11-18T12:00:00+08:00"
  },
  "sources": [],
  "nodes": []
}
```

### 8.2 查询模版允许的业务链路候选

`GET /api/collab/projects/business-chain/candidates?workspaceId=...`

只返回：

- 属于当前项目模版允许范围。
- `kind=business-chain`。
- `status=active`。
- 当前项目可访问。

### 8.3 校验绑定

`POST /api/collab/projects/business-chain/validate`

输入：

```json
{
  "workspaceId": "ws-so0101",
  "definitionId": "wfdef-business-chain-ai-server-v3",
  "nodeBindings": []
}
```

输出阻断、警告和通过项。

### 8.4 应用绑定

`POST /api/collab/projects/business-chain/bind`

必须携带 `revision` 和校验结果摘要。

### 8.5 启动实例

复用工作流现有实例启动 API。项目模块只更新 `businessChainWorkflowInstanceId`。

## 9. 响应式

- 1440px：页签内容全宽，节点表格显示完整列。
- 900px 以下：隐藏来源健康摘要列，保留节点和绑定状态。
- 640px 以下：
  - 页签横向滚动，不换行挤压。
  - 摘要单列。
  - 节点表格切换为单行堆叠。
  - 操作按钮保持 28px 高度，允许换行。
  - 不允许表格造成页面级横向滚动。

## 11. 验收标准

1. 项目设置中出现第三个页签「业务链路」，位置在「项目角色」之后。
2. 只有项目负责人或平台管理员能打开并修改。
3. 未绑定业务链路时显示明确空态，不自动选择任意工作流。
4. 候选列表只包含项目模版允许且启用的 `business-chain` 定义。
5. 模版仅配置一条链路时，页面显示“由项目模版提供”，不提供任意更换。
6. 节点来源绑定可预览、校验、应用，并支持来源延迟状态。
7. 应用绑定不修改已有运行实例和任务。
8. 运行中实例继续显示启动时定义快照。
9. 有未应用修改时关闭、切页或切项目会提示。
10. 项目概览只读展示绑定结果，不出现配置按钮。
11. 桌面和移动端无重叠、裁切或页面级横向溢出。
