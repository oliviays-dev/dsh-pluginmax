## 问题判断

### 订单事实

- 异常不是集中在单一类型，支付失败 52 单和履约超时 43 单合计占异常量 75.4%；
- 取消 31 单，占异常量 24.6%；
- 订单数据能定位区域、品类、渠道、商家、支付方式和金额影响；
- 订单数据不能直接证明支付渠道故障、仓库作业迟缓、具体 SKU 缺货或序列号问题。

### 人工核实

李工回执确认：

- 原履约仓中部分手机和平板 SKU 缺少可立即出库的完整序列号库存；
- 华东备用成品仓存在可用库存，其中 37 单可完成库存归属变更后转仓履约；
- 出库前需绑定 IMEI/SN，跨仓交接需要库存归属审核；
- 运输需保价并完成高货值交接，签收需身份核验；
- 发票与售后登记信息随订单同步。

以上属于人工仓配事实，不是 Data Agent 查询结果。
