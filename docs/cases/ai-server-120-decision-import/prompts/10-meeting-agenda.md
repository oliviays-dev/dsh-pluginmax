# 会议议程

## 会议标题

```text
AI Server 120 台订单 14 天交付决策会
```

## 建议参与者

- 供应链负责人（最终决策）
- 订单履行决策负责人 AI 伙伴（汇报与记录）
- AI Server 计划专员
- AI Server 采购专员
- AI Server 制造专员
- AI Server 质量专员
- AI Server 物流专员

## 会议目标

决定 A/B/C/D 中采用哪个方案，并确认对外承诺、采购审批、跨客户影响和剩余订单安排。

## 议程

### 1. 订单事实与风险

- 订单 120 台；
- 14 天最低 96 台；
- 商业风险 1,500 万元；
- 未达线时潜在损失和客户关系影响。

### 2. 数量桥

```text
130 → 降供 30% → 91 → +5 WIP → 96
→ +10 加价 GPU → 106
→ +20 跨客户 GPU → 116/120
```

### 3. 时间桥

- 普通 E2E 21 天，不可行；
- 空运 14 天，刚好压线；
- 生产追回 4 天不能直接视为整单缓冲；
- 必须在订舱、质量放行和起飞条件上留出人工检查点。

### 4. 方案比较

| 方案 | 按时 | 成本 | 关系影响 | 可行性 |
|---|---:|---:|---|---|
| A | 96 | 360 万 | 低 | 条件可行 |
| B | 106 | 860 万 | 供应商影响可控 | 默认建议 |
| C | 116 | 760 万 | 其他客户高 | 需关系审批 |
| D | 120 | 1,260 万 | 最高 | MES 未确认 |

### 5. 必须拍板的事项

1. 是否采用 B；
2. 是否批准 500 万元 GPU 加价采购；
3. 是否批准 200 万元空运；
4. 是否批准加班和 160 万元生产损失；
5. 是否保留 A 作为降级；
6. 是否允许 C 作为关系受损时的替代；
7. 剩余 14 或 24 台的交付安排；
8. 下一次复核时点。
