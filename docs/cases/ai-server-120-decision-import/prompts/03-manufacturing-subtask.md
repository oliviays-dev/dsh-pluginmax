# Manufacturing 子任务

## 标题

```text
[AI-SERVER-120-MFG] 确认 WIP、产能与生产效率损失
```

## 责任人

```text
AI Server 制造专员
```

## 描述

```text
请读取 MES 和 QMS Mock MCP，判断 96、106、116、120 台的 14 天制造与成品
检验放行可行性。质量不再是独立业务链路节点，而是本制造节点的内部门禁。

必须核实：
1. 5 台 WIP 是否已经占用 GPU；
2. 调整计划能否追回 5 台，并提前 4 天；
3. 8% 效率损失对应的 160 万元新增成本；
4. 96 台和 106 台的产能条件；
5. 116 台对其他订单的影响；
6. 为什么当前不能确认 120 台；
7. QMS 检验能力和质量 Hold；
8. 需要人工批准的加班、插单、订单让位和质量放行。
```

## 验收标准

```text
确认 5 台 WIP 可追回并已占用 GPU
确认 96 台可行、106 台在加班条件下可行
确认生产损失假设为 160 万元
明确 120 台当前未获得 MES 确认
确认 96/106 台可由 Quality 真人角色完成放行
确认 116/120 台仅为有条件质量可行
```
