# Planning 子任务

## 标题

```text
[AI-SERVER-120-PLAN] 计算供需、数量桥与四方案成本
```

## 责任人

```text
AI Server 计划专员
```

## 描述

```text
请读取 OMS、SRM、APS-PLANNING、MES、WMS、QMS Mock MCP，完成本案例的
供需与方案计算。

必须输出：
1. 130 个 GPU 降供 30% 后的 14 天有效量；
2. 数量桥：91、96、106、116、120 的来源和差额；
3. 时间桥：普通 E2E 21 天、空运 14 天和 4 天生产追回；
4. 方案 A/B/C/D 的按时数量、延期数量和综合成本；
5. 风险发生概率阈值：24.0%、57.3%、50.7%、84.0%；
6. 对供应商关系和其他客户关系的定性与定量双重说明；
7. 建议方案、失效条件和需要人工审批的事项。

禁止把 120 台产能当作已确认，禁止把 400 万元外部客户成本视为全部关系损失。
```

## 验收标准

```text
有效 GPU = 91
保底交付 = 91 + 5 = 96
方案成本 A 360、B 860、C 760、D 1,260 万元
明确 B 是默认建议、A 是降级、C 需关系审批、D 未确认
```
