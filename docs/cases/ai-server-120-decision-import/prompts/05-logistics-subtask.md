# Logistics 子任务

## 标题

```text
[AI-SERVER-120-LOG] 确认空运时效、费用与舱位
```

## 责任人

```text
AI Server 物流专员
```

## 描述

```text
请读取 WMS Mock MCP，完成本案例的运输测算。

必须输出：
1. 普通运输 21 天为什么不可行；
2. 空运 14 天为什么刚好压线；
3. 空运 200 万元是否覆盖单一批次 96/106 台；
4. 116 台和 120 台是否需要拆批或额外舱位；
5. 订舱截止、起飞和到达日期；
6. 没有 1 天安全缓冲时的客户承诺风险；
7. 质量未放行或单据不齐时的停止条件。

你只能完成内部数据查询和运输测算。订舱、承运商询价、运费确认、运输放行和
对外通知必须由人类执行或确认。
```

## 验收标准

```text
确认空运是 14 天窗口必要条件
确认 96 台和 106 台可按单一批次空运
确认空运名义缓冲为 0 天
明确需要书面舱位后才能升级承诺
明确方案仅为内部模拟，尚未订舱或对外承诺
```
