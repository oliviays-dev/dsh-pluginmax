# 根任务 Prompt

## 任务标题

```text
[AI-SERVER-120] 14 天交付 96 台与 120 台订单决策
```

## 新建任务字段

```text
类型：任务
项目：SO0101-战略客户X的AI Server交付
优先级：P0
初始状态：进行中
责任人：林岚（Order Fulfillment 人类）
完成后提交 Review：勾选
```

## 任务描述

```text
你是本案例的人类 Order Fulfillment 负责人林岚。

订单履行专员 AI 伙伴是你的内部助手。你可以在任务评论或会议中 @ 它，请它执行
OMS/APS 数据查询、数量桥校验、方案模拟和报告草稿。所有客户沟通、跨客户优先级
沟通、对外承诺、最终报告审核和会议发起必须由你完成。

客户订单由 100 台追加到 120 台，必须在 14 天内至少交付 96 台，否则存在
1,500 万元潜在商业风险。供应商预留 130 个 GPU，预计降供 30%，14 天有效
91 个。MES 有 5 台 WIP 可追回；采购可加价增加 10 个 GPU；还可以从其他
客户调拨 20 个 GPU，但会使对方延期 3-5 天。普通 E2E 21 天，空运 14 天
并增加 200 万元。

请拆分并驱动以下四个执行子任务：
1. Planning：数量桥、时间桥和方案成本。
2. Procurement：由人类采购执行，可按需 @ 采购 AI 伙伴查询 SRM 和起草审批包。
3. Manufacturing：WIP、产能、生产损失，以及 MES/QMS 成品检验放行。
4. Logistics：AI 可测算，订舱和承运商沟通必须由人类执行。

四个执行子任务完成后，由 Manufacturing 节点取得 Quality 真人放行，再创建一个
最终人工决策子任务给供应链负责人。

你必须：
- 只使用 OMS、SRM、APS-PLANNING、MES、WMS、QMS 的 Mock 数据和子任务回执；
- 如果当前环境已安装 Mock MCP provider，通过 MCP Tool 读取；
- 如果当前环境没有 provider，按文件名读取项目空间内六份 Mock Source Document；
- 不得在项目文件模式下声称“MCP 已连接”；
- 核对 130 → 91 → +5 WIP → 96 → +10 加价 → 106 → +20 调拨 → 116/120；
- 核对 96/106/116/120 的 14 天生产、质量、空运条件；
- 生成 A/B/C/D 四方案比较；
- 解释方案 C 虽比 B 少 100 万元并多交付 10 台，但会产生其他客户关系损失；
- 组织形成最终决策报告，并由你完成内部审核后提交给供应链负责人；
- 报告完成后由你发起会议 `AI Server 120 台订单 14 天交付决策会`；
- 会议结束后把人工决策、承诺和行动项写回本任务。

业务链路节点只写入常驻事实。生产可行性、160 万元损失估算、空运费用、
调拨建议和 A/B/C/D 方案比较作为任务评论、回执或报告内容，不写成业务链路字段。

默认建议为方案 B，方案 A 为降级。你不得未经供应链负责人批准就确认加价采购、
跨客户调拨、空运、加班、对外承诺或 120 台交付。
```

## 根任务验收标准

```text
完成三个 AI 执行子任务、一个 Procurement 人工子任务和一个人工决策子任务
数量桥 91 + 5 = 96、96 + 10 = 106、96 + 20 = 116 计算一致
方案 A/B/C/D 综合成本分别为 360、860、760、1,260 万元
明确空运 14 天没有自然安全缓冲
明确 MES 未确认 120 台 14 天产能
决策报告同时包含量化成本和供应商/客户关系影响
由人类订单履约负责人审核报告并发起供应链决策会议
已回写最终决定
```

## 根任务执行提示

```text
先创建 Planning、Procurement、Manufacturing、Logistics 四个执行子任务，
并在每个任务描述中使用对应的 Prompt 文件。Procurement 由人类承接。
所有子任务完成后，检查：
1. Planning 是否给出四个方案的数量、成本、风险阈值；
2. Procurement 是否确认 10 个 GPU 为增量供给；
3. Manufacturing 是否确认 106 台可加班交付；
4. Manufacturing 是否已取得 Quality 对 106 台的放行确认；
5. Logistics 是否确认 106 台可按单一批次空运。

任一岗位给出“未确认”，不得把对应方案写成确定可执行。

最后使用“最终决策报告模板”形成报告草稿，由人类订单履约负责人审核后发起会议，
等待供应链负责人做最终决策。
```
