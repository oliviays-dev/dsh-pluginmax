# AI Server 120 台订单 14 天交付决策报告

## 1. 一句话结论

建议采用方案 B：空运 + 追回 5 台 WIP + 加价采购 10 个 GPU。
14 天交付 106 台，综合成本 860 万元，不牺牲其他客户关系。

## 2. 订单事实

- 原订单：100 台
- 变更后：120 台
- 14 天最低交付：96 台
- 商业风险：1,500 万元
- 100 台利润：800 万元
- 120 台利润：待确认

## 3. 关键约束

- GPU 预留 130 个，降供 30%，有效 91 个
- 5 台 WIP 可追回
- 普通 E2E 21 天
- 空运 E2E 14 天
- 空运费用 200 万元
- 空运无自然安全缓冲

## 4. 数量桥

| 环节 | 数量 | 说明 |
|---|---:|---|
| GPU 预留 | 130 | 原承诺 |
| 降供后有效 | 91 | 130 × 70% |
| 追回 WIP | +5 | 已分配 GPU |
| 保底交付 | 96 | 满足最低线 |
| 加价 GPU | +10 | 总成本 500 万元 |
| B 方案 | 106 | 默认建议 |
| 跨客户 GPU | +20 | 对方延期 3-5 天 |
| C 方案 | 116 | 关系风险高 |
| D 理论数量 | 120 | MES 未确认 |

## 5. 时间桥

| 阶段 | 条件 |
|---|---|
| 原材料 | 91 个 GPU 在 2026-11-29 前可用 |
| 生产 | 追回 5 台 WIP，106 台在加班条件下可行 |

| 发运 | 2026-11-27 起飞，2026-12-03 到达 |

## 6. 方案比较

| 方案 | 按时数量 | 综合成本 | 关系影响 | 可行性 |
|---|---:|---:|---|---|
| A | 96 | 360 万 | 低 | 条件可行 |
| B | 106 | 860 万 | 供应商影响可控 | 推荐 |
| C | 116 | 760 万 | 其他客户关系高 | 需人工批准 |
| D | 120 | 1,260 万 | 最高 | 未确认 |

## 7. 关系影响

### 供应商关系

- 10 个 GPU 是增量供给，需书面订单和 ETA；
- 30% 降供背景下不得依赖口头承诺；
- 加价采购会增加依赖，但比跨客户调拨更容易治理。

### 客户关系

- 方案 B 不伤害其他客户；
- 方案 C 使其他客户延期 3-5 天，400 万元只覆盖账面成本；
- 客户信任、续约和内部协作损失无法由 400 万元完全覆盖。

## 8. 推荐与理由

推荐 B。相比 A，多 10 台数量缓冲；相比 C，多 100 万元成本但不牺牲其他客户；
相比 D，不依赖未确认的 120 台产能。

## 9. 待人工审批

- 加价采购 500 万元；
- 空运 200 万元；
- 加班和 160 万元生产损失；
- 是否允许跨客户调拨 20 个 GPU；
- 对外承诺 96/106/116/120 台；
- 剩余 14 或 24 台的交付日期。

## 10. 会议需要形成的决定

- 最终方案；
- 14 天承诺数量；
- 综合成本上限；
- 采购和调拨审批；
- 剩余订单安排；
- 风险接受人和下一次复核时间。
