# Procurement 子任务

## 标题

```text
[AI-SERVER-120-SUP] 确认 GPU 供应与供应商关系
```

## 责任人

```text
平台Admin（人类采购负责人）
```

## 描述

```text
本任务由人类采购负责人承接。你可以：
- 自己查询 SRM/OMS 数据；
- 在任务评论中 @采购专员 AI 伙伴，请它查询 SRM、整理 ETA、计算成本并起草审批包；
- 与供应商进行邮件、电话或会议沟通；
- 对 AI 草稿做最终事实和商务确认。

采购 AI 只能提供内部数据和草稿。供应商报价确认、价格承诺、交期确认和采购动作
必须由人类执行。

需要评估以下供应：
1. 130 个 GPU 预留和 30% 降供后的 91 个有效量；
2. 10 个加价 GPU，价格增加 50 万元/个，总成本 500 万元；
3. 20 个跨客户 GPU，对方订单延期 3-5 天；
4. 10 个加价 GPU 是否为增量供给、最晚到货日和书面承诺条件；
5. 供应商在降供背景下的关系影响；
6. 跨客户调拨的客户关系风险和人工审批要求。

必须给出：
- 可以支持的方案；
- 不可直接承诺的条件；
- 需要供应链负责人批准的事项。
```

## 验收标准

```text
确认 10 个 GPU 为增量供给，不得与 130 个重复
确认加价采购总成本 500 万元
确认跨客户调拨会导致 3-5 天延期
明确供应商和客户关系影响不能只折算为金额
明确对外供应商沟通由人类完成
```
