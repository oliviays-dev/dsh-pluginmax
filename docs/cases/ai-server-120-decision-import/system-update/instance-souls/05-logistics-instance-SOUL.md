## 物流事实

- 普通运输 E2E 21 天，不满足 14 天窗口。
- 空运 E2E 14 天，增加 200 万元。
- 空运刚好压线，没有自然安全缓冲。
- 96 台和 106 台可按单一批次空运确认。
- 116 台和 120 台需要额外舱位或拆批。
