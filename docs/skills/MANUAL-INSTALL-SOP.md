# Skill 手动上架与安装 SOP

## 1. 准备文件

使用以下 ZIP 包：

- `work-report.skill.zip`
- `competitive-analysis.skill.zip`

ZIP 内至少包含 `skill.json` 或 `SKILL.md`。当前包同时包含两者，安装时优先读取 `skill.json`。

## 2. 从资源市场上架

1. 进入「资源市场」。
2. 打开「Skill」页签。
3. 选择分类「自定义」。
4. 点击「注册资源」。
5. 在「上传 Skill ZIP、SKILL.md 或 .skill.json」处选择 ZIP 包。
6. 等待系统自动填充名称、说明、版本、开发者、权限和指令。
7. 检查名称无误后点击「注册资源」。
8. 注册完成后，在「自定义」列表点击 Skill 卡片右上角的「安装」。
9. 安装窗口默认只安装到「我的 Skill 资源库」。
10. 如需立即使用，可在「同时添加到 AI 伙伴（可选）」中多选可管理的 AI 伙伴。
11. 不选择 AI 伙伴时直接点击「确认安装」；选择后点击「安装并添加」。
12. 按钮变为「已安装」即表示资源库安装成功。

## 3. 安装到 AI 伙伴

如果安装时没有选择 AI 伙伴，之后需要重新打开资源市场的安装窗口，在「同时添加到 AI 伙伴（可选）」中选择目标实例。

1. 进入「AI伙伴」→「AI伙伴管理」。
2. 选择目标 AI 伙伴实例。
3. 打开「Skills」页签。
4. 在「自定义扩展」分组中确认或移除 Skill。

## 4. 移除与卸载

- 仅从某个 AI 伙伴移除：进入实例的「Skills」，在「自定义扩展」卡片上点击「移除」，资源库安装仍然保留。
- 从当前账号卸载：进入「资源市场」→「Skill」→「自定义」，在已安装 Skill 卡片上点击「卸载」。
- 卸载窗口会列出正在使用该 Skill 的 AI 伙伴；确认后先从这些实例移除，再删除账号安装记录。

## 5. 常见问题

- ZIP 无法解析：确认包内包含 `skill.json`，文件大小不超过 2MB。
- 注册按钮不可用：确认文件已解析且名称、指令不为空。
- 安装后 Agent 看不到：安装是账号级操作，需登录同一账号，并确认该智能体定义允许追加 Skill。
- 只能看到已安装但无法添加：该 Skill 可能已经加入当前实例，或平台策略禁止追加 Skill。

## 6. 已验证

已通过 GUI 使用两个 ZIP 包完成：

```text
资源市场 → 自定义 → 注册资源 → 上传 ZIP
→ 自动解析 → 注册 → 安装
→ 可选批量添加 AI 伙伴
→ 或进入 AI伙伴 → Skills → 添加
```
