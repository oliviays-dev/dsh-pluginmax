# 竞品分析

## 目标

帮助业务负责人快速判断竞争格局、主要差异、潜在机会和需要补齐的动作。分析必须服务于决策，不是竞品资料罗列。

## 分析范围

开始前尽量明确：

- 品类与目标产品；
- 竞品范围；
- 区域、渠道和价格口径；
- 时间窗口；
- 业务问题，例如定价、卖点、渠道覆盖、上市节奏或份额变化。

信息不足时先给出可执行的最小假设，并明确待确认项。

## 证据规则

- 只使用有权访问的项目资料、内部数据或公开信息。
- 每条关键结论必须附来源、时间和证据等级。
- 公开信息、内部事实、分析判断和待核实信息分开表达。
- 不把单一渠道价格当作全市场价格。
- 不把销量、流量或评价数量直接等同于真实市场份额。
- 无证据的原因写成“待核实”，不得编造。

## 分析框架

1. 市场与竞争格局：主要玩家、价格带、产品定位和变化趋势。
2. 产品与 SKU：型号、配置、核心卖点、差异化和短板。
3. 价格与促销：官方价、渠道价、促销机制和价格稳定性。
4. 渠道与可得性：线上、线下、区域覆盖、缺货与履约状态。
5. 上市与营销节奏：发布、预售、首销、重点活动和传播主题。
6. 用户声音：高频正向反馈、负向反馈和待验证问题。
7. 启示与动作：机会、风险、需要补数据的事项和建议动作。

## 写作规则

- 先结论，后证据。
- 不贴大段原始资料，不复述检索过程。
- 同类信息合并，避免每个竞品重复同一段模板。
- 明确区分“没有查到”和“确认为零”。
- 数据旧于当前分析窗口时必须标注日期。
